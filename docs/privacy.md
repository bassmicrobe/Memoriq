# プライバシーとアンインストール

[READMEへ戻る](../README.md)

MemoriqはMac内で処理します。アカウント、外部サーバーへのデータ送信、ページ本文やCookieの収集はありません。

## Chrome拡張の権限

| 権限 | 用途 |
|:--|:--|
| `tabs` | タブのURL・タイトル・最終アクセス・状態を読み、休止候補を判定します。 |
| `storage` | 許可・除外ホスト、未使用時間、自動休止設定、直近の実行件数やエラー状態をChromeプロファイル内に保存します。 |
| `alarms` | 自動休止を有効にした場合、約1分ごとに候補を確認します。 |
| `nativeMessaging` | 明示的な計測と手動休止の前後に、Macのメモリ情報をローカルアプリから取得します。 |
| `scripting` | 全サイト・一括整理で、ページ内の入力・再生状態を確認します。 |
| HTTP/HTTPSサイトへのアクセス（任意） | 全サイト・一括整理を初めて使う際に要求します。許可しなくても、従来の許可サイト方式は使えます。 |

拡張の設定は`chrome.storage.local`に保存します。休止の実行履歴には日時・件数・自動/手動の区別を保存し、タブのURLやタイトルは記録しません。

**退避を選んだタブのURL・タイトル・元のタブID・保存日時は、復元のため同じローカル領域へ保存します。** 最大500件です。URLには個人情報やアクセス用トークンが含まれる場合があります。同期・外部送信は行いません。「バックアップを保存」を押した場合だけ、URLとタイトルをHTMLファイルとして端末内へ書き出します。復元が確認できた記録は一覧から除きます。保存・復元に失敗した場合は復元情報を保持します。

任意のサイトアクセスは、全サイト・一括整理のボタンからChromeの確認を経て取得します。ページとフレーム内で入力値と初期値の差、編集領域、選択肢、メディアの状態を調べ、拡張へ返すのは判定・現在のフレームURL・子フレーム数だけです。入力内容・本文・Cookieの保存や外部送信は行いません。確認不能なら対象から除外します。ブラウザの拡張の権限設定からアクセスを取り消せます。権限を取り消した場合、全サイト・一括整理は確認不能として休止を見送ります。

拡張ページのContent Security Policyでも外部接続を禁止しています。休止前後の計測値は画面表示にのみ使い、履歴へ保存しません。

## Macアプリと連携

MacアプリはOSからプロセスの実行パスとメモリ使用量を読み、アプリ単位に集計します。連携で返す情報にはアプリ名・アプリパス・使用量・プロセス数・保護状態を含みます。

Native Messagingは固定の拡張IDを許可し、形式を検証した`snapshot`要求だけを処理します。拡張から任意コマンド、プロセス終了、ファイル操作を実行するAPIはありません。入力は64KiB、出力は1MiBを上限にしています。

管理者権限、アクセシビリティ権限、画面収録権限は不要です。ログイン時の自動起動も登録しません。

Mac側で休ませたアプリの名前・パス・終了前使用量は、Memoriqの起動中だけメモリ上に保持します。再起動の操作はネイティブ画面から行い、Chrome拡張やWebページからアプリを終了・再起動するAPIは追加していません。

## インストール先

標準のインストーラーは次の場所を使用します。

| 場所 | 内容 |
|:--|:--|
| `~/Applications/Memoriq.app` | Macアプリと、同梱したChrome拡張 |
| `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/jp.local.memoryharbor.json` | Chromeが読み取り専用ホストを起動するための登録情報 |

`jp.local.memoryharbor`は現在の内部識別子です。画面上の製品名はMemoriqです。

## アンインストール

1. Memoriqを終了します。
2. 退避データが残っている場合は復元するか、バックアップを保存します。拡張の削除後は、Chromeへバックアップをブックマークとして読み込めます。
3. Chromeの`chrome://extensions`でMemoriqを削除します。拡張に保存した設定・退避データも削除されます。
4. 上記のアプリとNative Messaging登録ファイルを削除します。

ソースを取得したフォルダや`dist/`のビルド成果物も不要なら削除できます。Chrome標準のメモリセーバー設定や、他のアプリの設定は変更していません。
